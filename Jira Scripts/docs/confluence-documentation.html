Jira Service Console

A single-user, menu-driven PowerShell console for Jira Service Management (JSM). It runs in a terminal and talks to Jira Cloud's REST APIs over HTTPS. There is no server, database, or build step — just .ps1 files you run directly.

1. Prerequisites

  • Windows with PowerShell 5.1 or later.
  • A Jira Cloud account that is an agent on the service desk project (required to reply, add notes, assign, and close).
  • A Jira API token — create one at id.atlassian.com/manage-profile/security/api-tokens.

2. One-time setup

  1. Open PowerShell in the project folder.
  2. Store your credentials (the token prompt is hidden while typing; secrets are saved as user environment variables, never written into the scripts): 
    .\Set-JiraCredentials.ps1
  3. Close and reopen PowerShell so the new variables load.
  4. If scripts are blocked by execution policy, allow scripts to run. Open PowerShell as Administrator and run one of the following (RemoteSigned is recommended and sufficient): 
    Set-ExecutionPolicy RemoteSigned

    If you still cannot run the scripts, use the more permissive setting:

    Set-ExecutionPolicy Unrestricted

    Answer Y (Yes) when prompted to confirm. You only need to do this once per machine.

About these commands: Windows blocks running .ps1 scripts by default. RemoteSigned allows local scripts to run while still requiring downloaded scripts to be signed — the safer choice. Unrestricted allows any script to run and should only be used if RemoteSigned does not resolve the issue. To scope the change to just your account instead of the whole machine (no admin needed), append -Scope CurrentUser, e.g. Set-ExecutionPolicy RemoteSigned -Scope CurrentUser.

3. Running it

.\Start-JiraConsole.ps1

On launch it authenticates and prints Signed in as <your name>.

4. Main menu

OptionWhat it does
1My tickets (all open) — every open ticket assigned to you, in one list.
2Unassigned queue — open tickets no one owns; view details, then pick up.
3Look up a ticket — by key (ITSD-5592) or bare number (5592).
QQuit.

5. The ticket list

Tickets display as an aligned table with columns: #, Key, Age, Status, Summary, Reporter.

  • Waiting for support rows get a loud red highlight so they stand out.
  • The Age column is colored by recency: green (< 4 hours), yellow (< 24 hours), red (older) — so the longest-waiting tickets are obvious at a glance.
  • Long values are truncated with an ellipsis so rows stay aligned.
  • At a list, press R to refresh (re-fetch from Jira), a number to open a ticket, or B to go back.

6. Viewing a ticket

Opening a ticket shows, in order:

  1. Header — key, summary, status, assignee, and the browse URL.
  2. Attachments — filenames tagged [image] or [file] (images can't render in a terminal, so open the ticket in a browser to view them).
  3. Description — the original request text, rendered to clean text.
  4. Activity log — the comment thread, each line tagged [PUBLIC] (customer-visible) or [INTERNAL] (staff-only), with author and time.

7. Ticket actions

KeyAction
RReply to customer — public comment. Asks for confirmation before sending.
IInternal note — staff-only, the customer cannot see it.
AAssign to me — take ownership of the ticket.
CClose — logs how long it took (required), then transitions to Done/Resolved. Returns you to the list afterward.
OOpen in browser — opens the ticket in your default browser.
MManageEngine — opens the ManageEngine remote-control console in your browser.
VRefresh the ticket and thread.
BBack to the list.

When composing a reply or note, type over one or more lines and press Enter on an empty line to finish.

8. Configuration

Edit the CONFIG block at the top of lib/Context.ps1:

SettingMeaning
$AttentionStatusThe status that gets the loud red highlight (default Waiting for support).
$ProjectKeyProject scanned for the unassigned queue and bare-number lookups (default ITSD).
$ManageEngineUrlThe ManageEngine remote-control link opened by the [M] action.

9. Architecture

The code is layered; each layer depends only on the ones below it.

Start-JiraConsole.ps1      entry point + main menu
  lib/Interaction.ps1      menus & prompts (the glue)
  lib/Display.ps1          render tickets      lib/Actions.ps1   change tickets
  lib/Data.ps1             read-only fetching (JQL + issue GET)
  lib/Helpers.ps1          pure utilities (time, text, columns)
  lib/Context.ps1          config + authentication

The entry point dot-sources every file in lib/, so all functions and $script: variables share one scope. That is how a data function can use the $script:Headers that authentication set up.

10. Jira APIs used

PurposeEndpoint
Who am IGET /rest/api/3/myself
Search ticketsGET /rest/api/3/search/jql
One ticket (+ rendered description)GET /rest/api/3/issue/{key}?expand=renderedFields
Read commentsGET /rest/api/3/issue/{key}/comment?expand=renderedBody
Write comment (public/internal)POST /rest/servicedeskapi/request/{key}/comment
AssignPUT /rest/api/3/issue/{key}/assignee
Log workPOST /rest/api/3/issue/{key}/worklog
Transitions (close)GET/POST /rest/api/3/issue/{key}/transitions

Note: reading comments uses the core API (clean rendered HTML plus the internal/public flag), while writing comments uses the Service Desk API — the only one that separates a public reply from an internal note.

11. Troubleshooting

SymptomCause / fix
"Missing credentials" after setupYou reused the same window. Open a new PowerShell window so the environment variables load.
401 UnauthorizedWrong email or mistyped token. Re-run Set-JiraCredentials.ps1.
403 when replying / assigning / closingYour account is not an agent on the service desk project.
Scripts won't runSet the execution policy (see step 4): Set-ExecutionPolicy RemoteSigned, or Set-ExecutionPolicy Unrestricted if needed.
Unassigned queue is emptyExpected when everything open is already assigned.

12. Security

  • Your token lives only in your Windows user environment variables, not in any script file.
  • To rotate the token, run Set-JiraCredentials.ps1 again.
  • Manage or revoke tokens at id.atlassian.com/manage-profile/security/api-tokens.

13. For maintainers

  • Functions use approved PowerShell verbs and carry comment-based help — Get-Help Complete-Ticket -Full after loading the library.
  • Lint with Invoke-ScriptAnalyzer -Path . -Recurse -ExcludeRule PSAvoidUsingWriteHost (Write-Host is intentional for this interactive UI).
